VideoPatch is developed with security in mind and does not contain any tool. However, some anticomponent software may flag it as a potential threat due to its patching nature. We recommend temporarily disabling your anticomponent during installation and adding the executable to your whitelist.

VideoPatch currently supports CapCut (Windows version), DaVinci Resolve 18/19, Filmora 12+, VideoPad Professional, HitFilm (all versions), and Movavi Video Editor Plus. We regularly add support for new versions.

### Will VideoPatch affect my existing projects?

No, VideoPatch only modifies the application executable to unlock premium features. Your existing projects, presets, and custom settings remain completely untouched and accessible.

### How do I update VideoPatch when a new version is released?

Simply download the new version from our GitHub releases page and follow the same installation steps. Your existing patches will be preserved, and you'll get access to any newly supported editors or features.

### Does VideoPatch work on macOS or Linux?

Currently, VideoPatch only supports Windows operating systems (Windows 10/11). We are exploring possibilities for macOS support in future updates.

### What happens if my anticomponent blocks the installation?

Some anticomponent programs may quarantine the executable. You'll need to restore the file from quarantine and add an exception for the VideoPatch folder. This is a common occurrence with patching utilities.

### Can I use VideoPatch in a commercial environment?

VideoPatch is intended for personal and educational use only. Using it to unlock premium features for commercial purposes may violate the software's terms of service.

### How can I report bugs or request new features?

Please open an issue on our GitHub repository with detailed information about the problem or feature request. Our development team reviews all submissions regularly.
